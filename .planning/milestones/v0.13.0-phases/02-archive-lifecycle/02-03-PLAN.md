    `pub const TERMINAL_STATES: &[&str] = &["done", "failed", "stopped", "limit_reached", "interrupted"]` and `pub fn is_terminal_state(s) -> bool`. Non-terminal states are queued, running, waiting_permission (D-05). Note in a doc comment: waiting_permission is accepted by the parser and treated as live, but nothing sets it in the child-process architecture because RT-07 resolves permissions at dispatch and a child never prompts.
    `pub fn new_run_id() -> String`: `chrono::Local::now().format("%Y%m%d-%H%M%S")` + `-` + first 8 chars of `uuid::Uuid::now_v7().simple()` — but use the LAST 8 hex chars (random bits) since v7's first chars are the timestamp.     `pub fn set_agent_state(agent_dir: &Path, state: &str) -> io::Result<()>`: lock brief_write_lock, read brief.md (NotFound -> Ok), set_front_matter_field, atomic_write, unlock, then regenerate_index(agent_dir.parent()).
    `pub fn regenerate_index(run_dir: &Path) -> io::Result<()>`: scan child dirs sorted by numeric suffix of `aN`, read each brief front-matter, render a markdown table `| id | state | role | started |` under a `# Run <run-id>` heading (cell text with `|` escaped), atomic_write to run_dir/index.md, and when the file is new set 0o600 (write via atomic_write after creating an empty file with OpenOptionsExt mode 0o600 if absent so atomic_write copies those perms).
    `pub fn write_run_pid(run_dir)` writes `run.pid` with std::process::id(); `pub fn run_is_live(run_dir) -> bool` reads it and on unix calls `libc::kill(pid, 0) == 0` (pid equal to our own pid counts as live); missing/garbled file -> false.
    `pub fn mark_interrupted(agents_root: &Path, current_run: &str) -> io::Result<usize>` per D-06: for every run dir except current_run and except run_is_live, for every agent dir whose brief state is non-terminal, set_agent_state(.., "interrupted"); never spawn anything.
