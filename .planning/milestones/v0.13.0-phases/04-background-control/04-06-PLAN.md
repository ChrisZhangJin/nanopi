<objective>
Close the CTL-06 gap from 04-VERIFICATION.md: continuing a finished agent that was dispatched by an earlier nanopi process in the same run currently fails with `no such agent: <id>`, because `SendMessageTool` only looks at the in-memory `AgentRegistry` snapshot.

Purpose: D-05 says continue "also works for agents from an earlier nanopi process in the same run". Today that is unreachable twice over: (1) every process mints a fresh run id in `AgentRegistry::new`, so no second process can ever be "in the same run"; (2) even if it were, the lookup has no disk fallback. This plan fixes both: a process may join an existing run via `NANOPI_RUN_ID`, and `send_message` reconstructs an `AgentEntry` from `agents_root/<run_id>/<id>/brief.md` (+ `report.md`) front matter, then feeds it into the existing `reactivate()` -> `prepare_continue` -> `spawn_continue_background` path.

Discretion choice (documented, not a locked decision): the run-joining mechanism is the `NANOPI_RUN_ID` environment variable, read once in `AgentRegistry::new`. It is the smallest mechanism that makes the cross-process case reachable without inventing CLI surface; it is stripped from child environments so children never join the parent's run.

Output: registry adoption API, send_message disk fallback, unit + integration + two-process e2e tests, CTL-06 flipped to `[x]`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model -> send_message `id` | model-supplied string used to build a filesystem path |
| environment -> NANOPI_RUN_ID | externally supplied run id selecting an archive dir |
| on-disk brief.md/report.md -> registry | files from an earlier process (or tampered) drive state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06-01 | Tampering (path traversal) | AgentRegistry::adopt_from_disk | mitigate | id must match `a[1-9][0-9]{0,18}` via valid_agent_id before any path join; front-matter id must equal requested id |
| T-04-06-02 | Tampering (path traversal) | NANOPI_RUN_ID | mitigate | accepted only if archive::is_run_id_shaped; otherwise ignored and a fresh run id is minted |
| T-04-06-03 | Elevation / integrity | adopt of non-terminal or interrupted agent | mitigate | refuse unless parsed state is terminal and not Interrupted (D-05); prevents double-running a live child from another process |
| T-04-06-04 | Spoofing | child inheriting parent run | mitigate | env_remove("NANOPI_RUN_ID") on every child Command, unit-tested |
| T-04-06-05 | Denial of service | joined run pruned by another process | mitigate | adopt/reserve write run.pid so run_is_live protects the joined run |
| T-04-06-06 | Information disclosure | error messages | accept | errors echo only the validated id / state token; no file contents |
</threat_model>
