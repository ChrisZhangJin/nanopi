<planning_decisions>
Open questions from 05-RESEARCH.md resolved during planning (conservative, CONTEXT-consistent):
- OQ1 "none exist": the strip is visible iff the registry snapshot for this run is non-empty (live and finished agents both shown, ordered per D-02, no TTL eviction).
- OQ3 activity source: use data already on disk, no Phase-1 runtime change. Each child already writes `transcript.jsonl` in its agent dir (src/tool/agent.rs ~line 984) with `{"type":"tool_call","tool_name":..,"arguments":..}` lines (src/session.rs SessionEntry::ToolCall). Activity = the last 3 tool_call entries, read by tailing at most the final 64 KiB of the file and parsing complete lines only. Result text for finished agents = the report state ("done", "failed", ...) plus "report ready" when report.md exists.
- Throttle: brief.md and report.md are re-read only when an agent first appears or its state changes; transcript tail is re-read for Running agents at most once per 1 s per agent. draw never touches the filesystem.
- "Waiting for permission" glyph is not implemented: the revision makes agents never prompt and AgentState has no such variant. Failed is the only attention state.
- Registry is unchanged; "most recently finished" ordering uses the Instant at which AgentsView first observed the terminal state.
</planning_decisions>

    - 1 agent -> height 2 (header + 1); 3 agents -> 4; 5 agents with 2 running -> 4 rows where the last is "+3 more (2 running)" (D-02: header + at most 3 lines, last becomes "+K more").

    - expanded_detail_lines(&view, width) returns, per agent: the agent line, up to 3 activity lines, "turns N · tokens M" when known, "worktree <path> (<branch>)" when present, "report <dir>/report.md" (D-04 fields).
