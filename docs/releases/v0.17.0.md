## Highlights

- **Model effort:** `/effort` shows or sets the thinking level. Supported Claude models receive adaptive thinking and an explicit effort setting; older models retain their token-budget format.
- **Persistent personal memory:** `/memory` manages reusable lessons and environment notes. The model searches the distilled library only when a task points back to earlier work; the search tool is omitted when the library is empty. Environment notes require explicit disclosure for the receiving endpoint.
- **Dream maintenance:** `/dream` consolidates daily notes, reviews old entries, and records what changed. Optional nightly scheduling on Linux uses a systemd user timer or falls back to the user's crontab. No sudo is required. `/dream status` and `/dream log` show progress and decisions. Dream works from daily notes, not old raw transcripts.
- **Live agent panel:** Open `/agents`, select with ↑/↓, and press Enter to open a read-only right-hand panel showing the agent's activity and output. Input still goes to the main orchestrator. Use `/agents close` to return to the normal view.
- **Shared agent status checks:** One watcher covers all active agents. The model chooses the next check interval; the watcher reports status without messaging or stopping agents and is independent of `/loop`.
- **Windows builds:** Guarded Unix-only sudo detection so Windows can build again. Sudo is unavailable on Windows.
